# Calculator
A calculator designed in grey and cyan.

Consists of different modes such as basic, scientific, equation and matrix calculator;

(Tho for now only basic and scientific are done)

Implemented a local Storage system so that the files doesn't lookse information on refreshing.
Also implemented a history portal which shows the last 20 calculations done by the user in the history-list. 


To open the File : 

Downloand the git hub repo (sadly havent yet introduced a live test demo server for this project)
Use live-server extension and open the file main.js
